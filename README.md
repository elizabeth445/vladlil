# Дві маленькі історії

Локальное акварельное приглашение на второй день рождения Владислава и Лілії. Весь интерфейс — на украинском. Внешние сервисы и ключи не нужны.

## Запуск

Нужен Node.js 24+ (локальная база использует встроенный `node:sqlite`).

```sh
source ~/.codex/bin/frontend-env.sh
npm install
npm run dev
```

Открыть **http://127.0.0.1:3000**. Сервер слушает только локальный адрес. Для повторного запуска можно дважды нажать `start.command` в Finder.

Вступление проигрывается при каждой загрузке страницы. Его также можно повторить кнопкой-конвертом в шапке и кнопкой «Відкрити конверт ще раз» внизу.

## Визуальные замечания через Agentation

В режиме `npm run dev` доступна панель Agentation в правом нижнем углу. Нажмите её значок, выберите элемент, напишите замечание и скопируйте результат кнопкой Copy, чтобы передать его в чат. Это инструмент аннотаций для последующих правок в коде, а не редактор, который сам меняет сайт.

Панель работает на desktop. В production-сборке (`npm run build` и `npm run start`) она отключена. Данные заметок остаются в браузере: внешние серверы, MCP и webhooks не настроены. Глобальные горячие клавиши Agentation отключены, чтобы не мешать формам и открытию конверта.

## Что работает

- Бумажный конверт с GSAP-анимацией, пропуском, клавиатурой и reduced motion.
- Живые акварельные герои, бабочки и воздушные шары, параллакс отдельных слоёв при прокрутке.
- Львёнок и котёнок отвечают на нажатия, а с бабочкой можно играть.
- Кнопка-конверт в шапке повторно открывает вступление, не удаляя черновики анкет.
- Шары таймера разлетаются при прокрутке и лопаются с конфетти по нажатию. Их можно вернуть повторным нажатием по одному.
- Обратный отсчёт до 15 ноября 2026, 16:00 Europe/Kyiv; корректное состояние после события.
- Ноябрьский календарь с автоматически рисующимся сердцем вокруг 15 числа и загрузкой `.ics`.
- FRANCO, адрес, маршрут Google Maps и официальный сайт.
- Две независимые анкеты с сохранением в локальную SQLite, отдельная RSVP-форма.
- Закрытая страница `/admin`: фильтры, все ответы, экспорт CSV и выход.

## Локальные данные

При первом обращении к формам или админке создаётся `.data/`. Не удаляйте её, если хотите сохранить ответы.

- `invitation.sqlite` — база ответов. При работающем сервере вместе с ней могут существовать `-wal` и `-shm`.
- `admin-access.txt` — автоматически созданный пароль для `/admin`.
- `auth.json` — серверные секреты и хеш пароля.

Все файлы исключены из Git; секреты не передаются браузеру. Папка доступна только владельцу компьютера. Пароль можно посмотреть локально в `admin-access.txt`. Не публикуйте эту папку. Для резервной копии остановите сервер и скопируйте `.data/` либо выгрузите CSV.

При локальной работе ответы сохраняются на этом компьютере.

## Публикация на Vercel

Импортируйте репозиторий как Next.js-проект с Node.js 24. Команды установки и сборки определяются автоматически по `package-lock.json` и `package.json`.

На Vercel по умолчанию включён режим черновиков: поля анкет и RSVP сохраняются в `localStorage` этого браузера, отправка на сервер отключена, панель организаторов и экспорт недоступны. Интерфейс прямо сообщает, что ответы не отправлены. Анимации и календарь работают полностью. Локальная база и пароли из `.data/` не загружаются.

Режим задаётся при сборке через `NEXT_PUBLIC_SUBMISSIONS_ENABLED=false`; Vercel определяется автоматически. Для публикации с работающей отправкой нужно сначала подключить постоянное хранилище, затем менять этот флаг. SQLite в файловой системе Vercel для этого не подходит.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

Playwright использует установленный Google Chrome и WebKit с эмуляцией iPhone в отдельных временных профилях. Личный профиль не используется. Тесты проверяют ширины 320, 375, 390, 430, 768, 1024 и 1440, независимость анкет, сохранение, ошибки сети, валидацию, идемпотентность, календарь, вход/выход и доступность axe.

## Визуальные материалы

`public/art/` содержит оптимизированные локальные WebP:

- `lion.webp`, `kitten.webp` — оригинальные акварельные персонажи, созданные встроенным ImageGen по референсам пользователя.
- `celebration-frame.webp`, `celebration-frame-mobile.webp` — оригинальные акварельные обрамления, разная композиция для desktop и mobile.
- `franco.webp` — фасад с официального сайта [FRANCO](https://franco.net.ua/). Источник: `https://franco.net.ua/wp-content/themes/franc/img/a1c9d71e-3ae9-4f6d-854a-b533e3a483cd-2.jpg`.

Промпты ImageGen: акварельный львёнок с короной, голубым бантом, машинкой и мячом; пушистый кремовый котёнок с розовым бантом, цветами и бабочкой; прозрачные рамки с голубыми и розовыми шарами, облаками и цветами, пустым центром для HTML-текста. Использован встроенный ImageGen, прозрачность сохранена.

Shantell Sans и Onest размещаются локально через Fontsource; украинские І, Ї, Є, Ґ включены в кириллические диапазоны. Для анимаций используется только GSAP и CSS, без второго цикла smooth scrolling.
